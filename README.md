# R-written-scripts

A collection of useful R scripts.

## Structure

- `R/` - Main R scripts and functions
- `data/` - Sample data files
- `tests/` - Unit tests
- `.gitignore` - Git ignore patterns for R projects

## Usage

Source scripts from the `R/` directory:

```r
source("R/script_name.R")
```

## Requirements

- R (>= 4.0.0)
